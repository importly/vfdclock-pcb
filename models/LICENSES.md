# Model sources

Where each model file in this folder came from and when it was added. Check the licence of each source before you share or sell a design with the model: manufacturer models usually allow use in designs but not redistribution, and KiCad's packages3D models are CC-BY-SA 4.0 with an exception that lets designs and generated files use them freely.

- `adafruit-4829-sgp40.step` (Adafruit_CAD_Parts, MIT licence): https://raw.githubusercontent.com/adafruit/Adafruit_CAD_Parts/main/4829%20SGP40%20Sensor/4829%20SGP40%20Sensor.step, added 2026-11-01
- `adafruit-5187-scd4x.step` (Adafruit_CAD_Parts, MIT licence; the SCD-40 and SCD-41 boards share one layout): https://raw.githubusercontent.com/adafruit/Adafruit_CAD_Parts/main/5187%20SCD-40%20C02%20Sensor/5187%20SCD-40%20C02%20Sensor.step, added 2026-11-01
- `vfd-gu256x128c-3900.wrl`: written for this repo from measurements of the owner's display, no third-party content.
- `devkit-esp32s3-devkitc1.wrl`: written for this repo, the devkit's bare board, no third-party content.
